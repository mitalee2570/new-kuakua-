PRETUTE E-Commerce Platform - Code Structure & File Editing Guide

This document provides a complete map of the codebase. Whenever you need to customize text, photography, styles, buttons, or admin panel configurations, consult this guide to locate the exact source files.

1. Design, Styling & Fonts (CSS Files)

File Path Type Customization Scope
frontend/src/style.css Storefront CSS
  • Brand Colors: Primary accent (#FF5B7F), deep navy (#1A253C), price green (#22c55e).
  • Typography: 'Outfit' and 'Inter' font scale and hierarchy.
  • Buttons & Cards: Add to Cart, Buy Now, shadows and hover micro-interactions.
  • Responsive Grid: Mobile breakpoint adaptations and layouts.
frontend/src/admin.css Admin Panel CSS
  • Admin sidebar themes and dark backgrounds (#1A253C).
  • Tables, form inputs, and 6-angle image upload preview grids.
  • Pill badges for status (Active, In Stock, Sale).

4. Admin Panel Architecture

Primary Admin File: frontend/src/components/admin/AdminLayout.jsx
All admin operations (PIN authentication, 6-angle image management, products, categories, coupons, and orders) are contained within this component.
Feature Location in Code Customization Scope
Admin PIN Lines 11-14 and loginAdmin Default PIN: 2570.
6-Angle Photo Slots Tab 2: productModalTab === 'photos' Six perspective slots with file upload and URL paste support.
1-Click Coastal Tray handleFillCoastalTemplate One-click auto-fill utility for the 6 Coastal Tray demonstration photos.
Catalog Fields Tab 1: productModalTab === 'info' Product Title, SKU, Brand, Category, Sub-Category, and Tags.
Pricing & Colors Tab 3: productModalTab === 'pricing' Selling Price, MRP, discount percentage, and color palette swatches.
Description & Specs Tab 4: productModalTab === 'details' Short description, detailed craftsmanship story, dimensions, and care notes.
Our Latest Products Tab activeTab === 'latest_products' Product inventory table with direct addition, edit, and deletion capabilities.
Banners, Categories & Coupons activeTab === 'banners' / 'categories' / 'coupons' Forms for adding and editing banners, category taxonomy, and discount codes.

5. Data Stores & JSON Files

7. Quick Reference: "How do I change X?"

Objective File to Modify Guidance
Change Brand Color Scheme frontend/src/style.css Update --color-primary and #FF5B7F with your target hex code.
Modify Login Popup Timing frontend/src/App.jsx Change the timer threshold (e.g., 10000 ms to 5000 ms).
Change Admin PIN backend/routes/admin.js Replace default 2570 with your designated 4-digit code.
Add Product Directly to Database backend/data/products.json Append a new product entry at the top of the JSON array.
Update Latest Products Section Heading frontend/src/components/home/LatestProducts.jsx Edit the title or subtitle strings directly in JSX.
Update Footer Contact Information frontend/src/components/common/Footer.jsx Update telephone numbers, email addresses, and social handles.
